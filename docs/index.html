02 / PROJECTS

My work.

TU EINDHOVEN · 2025–2026

Restaurant Digitalization

Gathered input from four restaurants and 65 customers, translating the findings into 35 prioritized requirements for an AI ordering assistant.

Built a scheduled Databricks workflow to validate 221 simulated customer sessions and stored validated data in Delta Lake.

Analyzed ordering interface variants with SQL and developed Logistic Regression and XGBoost models for order completion, achieving approximately 0.79 ROC AUC.

PYTHON · SQL · DATABRICKS · DELTA LAKE
ENEXIS · 2024

Electricity Forecasting

Developed PySpark workflows in Azure Databricks to prepare electricity load records for forecasting.

Created lag, rolling average, and calendar features. The data processing workflow ran in 1 minute and 2 seconds in the development environment.

Used chronological training for a GRU forecasting model, achieving 7.63% MAPE.

PYSPARK · DATABRICKS · GRU
PHILIPS · 2024–2025

Digital Pathology

Managed an Agile project exploring intelligent assignment of pathology cases, working with Philips’ Pathology team.

Assessed database schemas and documented six high-priority and five medium-priority data quality gaps.

Aligned open-source data with Philips’ schema and explained the implications of data gaps to nontechnical stakeholders.

DATA QUALITY · DATA MODELING · AGILE
UNIVERSITY OF GRONINGEN · 2021

Learning from Brain Scans

Integrated FDG PET data from three hospitals into a consistent dataset and corrected hospital-specific bias for my master’s thesis.
